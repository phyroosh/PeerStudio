# PeerStudio 🚀

![PeerStudio Banner](https://img.shields.io/badge/PeerStudio-AI%20YouTube%20Studio-00F5D4?style=for-the-badge&logo=youtube&logoColor=white)

**PeerStudio** is a next-generation AI-powered YouTube Studio application built with Flutter. It's designed to help creators optimize their channel strategy, increase engagement, and streamline their workflow using cutting-edge AI models from OpenAI, Anthropic, and NVIDIA NIM.

## ✨ Features

- **Modern Cyber-Minimalism UI/UX:** A stunning dark-mode interface with glassmorphic elements, smooth custom animations, and bouncy physics-based buttons.
- **AI Strategy Center:** Automatically analyze your video performance and generate higher-converting titles, thumbnails, and tags.
- **Smart Auto-Responder:** Let AI analyze the context of your comments and draft highly engaging, contextual replies.
- **Secure Local Vault:** Safely store your YouTube Cloud Console credentials and API keys directly on your device.
- **Advanced Data Visualizations:** Beautiful, custom-drawn cubic curve charts that animate your channel's real-time growth.

## 🛠️ Built With

*   **Flutter** - The UI toolkit for building natively compiled applications.
*   **Google APIs** - For YouTube Data API integration.
*   **Shared Preferences** - For secure local storage of keys.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites

*   Flutter SDK (latest stable version)
*   Dart SDK

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/phyroosh/PeerStudio.git
   ```
2. Navigate to the project directory:
   ```sh
   cd PeerStudio
   ```
3. Install dependencies:
   ```sh
   flutter pub get
   ```
4. Run the app:
   ```sh
   flutter run
   ```
